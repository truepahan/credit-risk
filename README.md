# Система анализа кредитных заявок

Продолжение исходного проекта. Курсовая объединяет анализ, моделирование и локальный сервис.

## Запуск
Python 3.14.6, Windows; GPU не нужен.

```powershell
py -3.14 -m venv .venv
.venv/Scripts/activate
python -m pip install -r requirements.txt
python -m src.reproduce
python -m pytest -q
python -m src.service
uvicorn src.api:app --host 127.0.0.1 --port 8000
```

API: http://127.0.0.1:8000/docs. Панель: notebooks/03_credit_dashboard.ipynb.
Исходный notebook 01_eda.ipynb содержит EDA из второй практики; 02_dashboard.ipynb — ранний прототип без модели.
Основной конвейер: split → train → batches → verify. Старый src/pipeline.py сохранён как этап подготовки из исходного проекта, но не используется для CV.

## Результаты
ROC-AUC теста 0.9361; AP 0.8848; полнота 0.8100 при пороге 0.18. Выбран HistGradientBoostingClassifier.
Метрики и условия воспроизведения: reports/model/result.json, reports/verification.json.
11 тестов пройдены. 
Кандидат переобучения сохранён отдельно; рабочая v1 не заменена.

## Ограничения
Учебные данные без временных меток. Порции не являются календарными периодами. Метки не используются при прогнозе.
Ставка и рейтинг должны быть известны в момент оценки. Условные потери с LGD=0.45 не являются банковским нормативным резервом.
API проверен TestClient без внешней сети. 8 ГБ ОЗУ отдельно не испытывались. Конкурентная обработка одинаковой порции не поддерживается.
Окончательное кредитное решение принимает специалист.

## Воспроизводимость
Запуск на полностью чистом компьютере не проверялся; точные зависимости сохранены в requirements.txt.
Для полного пересчёта выполните `python -m src.reproduce`. Для отката верните доверенный model_v1.joblib и перезапустите API (модель кешируется в процессе).

## Изменения относительно практик
- Предобработка обучается заново внутри каждого блока CV.
- Сохранены восемь признаков и исходный стек.
- manual_review блокирует автоматическое прогнозирование.
- При оценке порций исключены совпадения входов с исходной частью.
- Исправлен смысл loan_percent_income: сумма кредита / годовой доход.
- Детальное сравнение моделей, API, мониторинг, идемпотентность и переобучение добавлены как продолжение проекта.

## История практик

| Тег | Этап |
| --- | --- |
| `pr1` | Постановка задачи и требования |
| `pr2` | Подготовка данных и разведочный анализ |

| `pr4` | Оценка модели и обработка порций |
| `pr5` | API, мониторинг и проверка системы |
