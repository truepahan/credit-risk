# Практика № 1. Постановка задачи

Система анализирует кредитные заявки и оценивает риск дефолта. Входом служат данные заявки, выходом — оценка риска для специалиста. Целевая переменная `loan_status` принимает значения 0 и 1.

Сначала проверяется качество данных, затем строятся признаки и сравниваются модели. Для отделения рискованных заявок используются ROC-AUC и полнота при выбранном пороге. Программа проверяет новые порции, хранит результаты и предоставляет локальный API.

История восстановлена по материалам практик и итоговому коду. Теги отмечают восстановленные этапы, а даты коммитов соответствуют восстановлению.
